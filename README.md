# OpenWhip Creator

OpenWhip Creator 是一个 DIY AI 等待反馈作品生成器。

你可以上传一张喜欢的角色、表情包、图标或道具图，把它变成等待 AI 时出现的小反馈：按一下快捷键，或说一句关键词，它就用不同颜色、动作和话术回应你。

## 你可以做什么

- 上传自己的 PNG / JPG / WEBP 图片。
- 生成像素风角色预览和 6 种颜色状态。
- 设置 `Option + A/S/D/F/G/H` 六个触发按钮。
- 自定义关键词、动作和气泡话术。
- 下载一个可分享的互动反馈作品包。

## 怎么用

直接打开：

```text
index.html
```

然后按这个顺序操作：

1. 上传一张图片。
2. 看右侧实时效果预览。
3. 修改每个按钮的关键词、动作和话术。
4. 下载你的作品包。

## 使用边界

这个工具不会让 AI 真的变快，也不会打断任务或读取隐私。它只是把等待时的情绪，变成一个更好玩、更可见的小反馈。
